### T1 — Agent Adapters
**Requirements:** `HND-1..2`
**Artifacts:** Adapters for `agy` and `opencode` in `worker/agent`
**What to do:** Implement the `AgentRunner` interfaces for both real agents based on the Spike A results. Handle subprocess execution, stream parsing, timeouts, and returning structured results.
**Acceptance:** Adapters successfully run agents headless and return the expected artifacts.

### T2 — Prompt Templates
**Requirements:** —
**Artifacts:** Prompt templates for `spec`, `probe`, `coding`, and `review` roles.
**What to do:** Design and test system prompts and contexts passed to the agents. Ensure determinism over prompt constraints is respected.
**Acceptance:** Templates generate consistent, valid outputs against the real agents.

### T3 — Human Handoff and Skill
**Requirements:** `HND-1..6`, `CLI-3`
**Artifacts:** `garagefab-work` skill, `garagefab install-skills` command
**What to do:** Implement the handoff command generation. Build the CLI command to install the skill to agent config directories. Build the skill itself to interact with the local Garagefab API.
**Acceptance:** Skill installs successfully, fetches job details, and can post clarification answers back to the API.

## Exit Criteria

## Risks

| ID | Risk | Mitigation |
|----|------|------------|
| R1 | An agent CLI has no dependable headless mode | Spike A first; design the adapter so a PTY-based launcher can be added |
| R2 | Agents produce invalid or missing artifacts | Strict schemas, repair loop, prompt templates tested against recorded fixtures |
| R3 | Agent CLIs change flags between versions | Record tested versions, detect version at start, contract tests on fixtures |
