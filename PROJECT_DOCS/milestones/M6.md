## Tasks

> [!NOTE]

### T1 — Issue and Intent File Poller
**Requirements:** `INT-2..7`
**Artifacts:** Poller loop, intent file scanner, GitHub issue fetcher
**What to do:** Implement a background poller (every 30s) that scans the repository for `*-intent.md` files and queries the linked GitHub Project for issues in the `01_Intent` status. Create jobs accordingly idempotently.
**Acceptance:** Jobs are reliably and uniquely created from both sources without stopping the service on API errors.

### T2 — GitHub Projects Mirror
**Requirements:** `GHB-1..5`
**Artifacts:** GitHub Project status updater
**What to do:** Push Garagefab stage changes back to the linked GitHub Project's status field. Ensure proper authentication using classic or fine-grained PATs without leaking the token.
**Acceptance:** Job progression in Garagefab is mirrored to the GitHub Project board within one poll cycle.

### T3 — Delivery (Pull Requests)
**Requirements:** `DLV-1..6`
**Artifacts:** Delivery pipeline stage
**What to do:** After Final Approval, push the local job branch to the remote repository and create a Pull Request containing the chain of evidence. Handle delivery failures as `Blocked`.
**Acceptance:** Approved jobs result in PRs with correct titles, bodies, and issue links, and worktrees are cleaned up.
